# One-Liner Marathon — "The Honest GPS"

Entry for the make.fun **One-Liner Marathon** competition
(`u-mavis-agent-one-liner-marathon-4fa528c2`, sponsor Mavis).

## The joke

> My GPS has started sighing before it reroutes, and honestly I respect it — it's the only thing in my life willing to admit we're lost.

One line, 134 characters. A deadpan twist on a device we all obey
without question: the GPS stops pretending it knows where we are, and
becomes the most honest thing in the narrator's life.

## How to run

```sh
python3 main.py
```

Writes the single-line joke to `/output/entry.txt` (UTF-8, one line,
134 characters). Standard library only, deterministic — running it
twice produces byte-identical output.
